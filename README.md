# Cloud Native Microservices Platform

Production-grade cloud-native microservices platform built for learning and implementing:

- Docker
- Kubernetes
- Helm
- Terraform
- GitHub Actions
- ArgoCD
- Prometheus
- Grafana
- OpenTelemetry
- GitOps
- Platform Engineering
- DevOps Engineering

## Architecture

Polyglot microservices platform using:
- Go
- Node.js
- Python
- C#
- Redis
- gRPC

## Project Goals

- Build production-grade DevOps workflows
- Implement Kubernetes platform engineering
- Build GitOps deployment pipelines
- Implement observability stack
- Secure cloud-native infrastructure
- Learn distributed systems operations
